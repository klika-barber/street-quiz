# Street Quiz Pro — Klika

Aplikacja do quizów i sond ulicznych. Otwórz https://klika-barber.github.io/street-quiz/ na telefonie i zainstaluj:
- Android (Chrome): menu ⋮ → Zainstaluj aplikację
- iPhone (Safari): Udostępnij → Do ekranu początkowego

Dane uczestników zapisują się tylko w telefonie — to repozytorium zawiera wyłącznie kod aplikacji.
